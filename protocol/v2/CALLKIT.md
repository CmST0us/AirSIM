# 原 App 视图与 v2 系统通话

2026-10-25。沿用 R4/R5 的身份、命令收据与媒体协议。本阶段将 ECS v2 接入原 App，保留本地、云端 v1、云端 v2 选择。通话质量优化暂缓。

## M1：共用原视图

- 所有版本使用 `RootView` 的拨号、最近、短信、联系人、设置五个标签及原 `ActiveCallView`。删除独立 `CloudV2Host` / 三标签产品入口。保留原导航、外观、联系人选择、`tel:` / `im:` 导航。
- `AppModel` 继续作为现有视图的数据与动作入口，组合可选 `CloudV2Model`。v2 初始化必须在旧 Watch、VoWLAN、旧云媒体及推送启动之前分支；不得为了呈现视图而启动旧运行时。v1/local 行为保持原路径。
- v2 状态投影到现有通话/短信展示模型，实际命令、持久化与媒体继续由 `CloudV2Model` 负责。历史 ID 保留服务、安装实例、模块与设备代次的隔离；显示模型不能反向决定控制目标。动作使用已有受验证的 binding/owned-call 和单次命令状态机。
- 原设备卡和选择器承载 v2 模块。导入配置、连接、模块选择与连接状态纳入原首次连接和设置视图。首次选择模块仍需用户显式选择，切换模块不得带入另一模块的历史、草稿或通话。
- 通话接听、拒接、挂断、静音、扬声器和 DTMF 从原界面进入 v2。静音/扬声器状态取实际 v2 媒体。录音及没有对应 v2 能力的维护操作不展示可点击的假入口；不向 v1 API 发送 v2 操作。
- M2 接入系统通话后，新安装默认启用通话音频，已有显式音频偏好保持不变。设置使用“通话音频”名称；协议中的 `experimental_audio` 字段保持兼容，音频质量未验收的事实保留在验收记录。
- 短信沿用列表、会话、撰写器和联系人入口，发送成功以命令终态为准，未知结果保留并显示待核对。刷新与清理通过模型动作，不允许视图直调旧 `model.api`。v2 清理仅清除当前服务/安装/模块的本地副本，不批量确认或删除模块短信。
- 连接、离线、未选模块、权限拒绝、凭据过期、未确认命令均给出中文状态与可执行恢复入口。内部 UUID、英文状态码和详细诊断移入诊断页，不作为主页面说明。
- M2 负责 CallKit 与已有通话的后台生命周期。原 v1 和 local 的设置仍可用，v2 不显示三星配对、v1 Relay 自检或 v1 录音入口。


## M2：CallKit 与已有通话的后台生命周期

- v2 在前台从已验证的新鲜快照发现来电后，上报 CallKit 系统来电界面。同一通话保持稳定的系统 UUID；重复快照、已结束通话及旧身份域事件不得创建第二份系统通话或控制新模块。
- 系统与原 App 界面的拨号、接听、拒接、挂断、静音和 DTMF 使用同一个运行时及已验证的 v2 binding/owned-call。CallKit 委托以 handler generation 与 call UUID 隔离，不能打开旧运行时的网络闸门。
- 命令 HTTP 202 与等待收据属于进行中状态。系统拨号/接听确认用户动作后，保留同一 CallKit UUID 并只读等待原命令关联，最长 25 秒；明确失败或超时才结束本地系统通话；确定拒绝或失败终态按原规则确认清理，未知命令仍保留且不重发。关联前用户结束通话时，最多等待原命令关联 10 秒，再使用确切 call ID 定向挂断；无法关联时保留待核对。短信仍须命令完成才显示发送成功。
- 普通进入后台不挂断由本 App 管理的 v2 通话。已有系统通话仅保留快照轮询、所属控制与媒体；短信、目录轮询暂停。闲置时停止后台轮询，不把后台通话授权扩大为任意后台拨号或发短信。
- CallKit `didActivate` 后才启动真实音频，`didDeactivate` 暂停音频。音频组件配置路由，但不抢先激活系统 AudioSession。静音和扬声器状态反馈到原通话视图。
- 远端结束、凭据撤销、网络失败及 provider reset 完成定向清理；provider reset 对已拥有通话只提交一次定向挂断。保留快照时效、设备代次、命令幂等和媒体票据限制，未知结果按原收据恢复。
- 当前生产 ECS 保持 `airsim-v2-r4.1`。App 也接受关闭推送的已知 `airsim-v2-callkit` 服务，继续拒绝未知 profile、身份不符及未支持的推送能力。CallKit 接入不依赖 APNs 注册或数据库升级；App 的连接与版本/模块切换不受推送注册状态阻塞。
- v2 空闲后台或被系统终止后的来电唤醒不在本阶段范围；原 v1 PushKit 路径保留。设置明确当前后台能力，不将“服务器连接成功”等同于“后台来电已就绪”。Watch v2 不支持。

可选的服务端推送准备及尚未启用的客户端契约单列于 [APNs 扩展](APNS_EXTENSION.md)，不作为本阶段验收条件。

## 验收与提交

M1 提交共用视图与原导航适配；M2 提交 iOS CallKit 与通话生命周期；M3 提交设计/QA 反馈修复与回归证据。各里程碑使用明确路径暂存，不带入其他工作区改动。

QA 覆盖五标签、连接与模式切换、模块隔离、联系人/历史拨号、短信会话、权限/异常态、系统 URL、前台发现来电、系统接听/挂断、重复事件隔离、远端结束、provider reset、已有通话进入后台及 CallKit 音频激活/停用。模拟器与替身测试证明 UI/逻辑；真机系统界面、后台通话与硬件音频单独记录，不互相替代。设计和 QA 不做技术决策，问题交 iOS 执行会话，由主控定方案。
