# AirSIM 添加设备 · HTML 设计稿

打开 `index.html`，或在仓库根目录运行 `python3 -m http.server 4173 --bind 127.0.0.1 --directory design/pairing-web`，访问 `http://127.0.0.1:4173/`。

## 用户界面

选择设备 → 核对设备 → 连接设备 → 显示连接结果。

界面使用设备名称、标识和连接状态。设备列表、无设备、连接失败、连接完成可通过页底预览工具查看。“连接设备”和“查找设备”进入等待状态；没有计时器模拟成功。

系统字体、灰白底色、分组圆角面板与蓝色主按钮构成页面视觉。文案使用操作与结果短句。

## 接入边界

本页为交互设计稿，RM500 与 A7K2 是示例，不读取设备、不收集凭据、不执行真实连接。

现有设备列表与连接状态来自 [三星发现与配对](../../iOS/AirSIM/SamsungPairingView.swift) 和 [模块连接视图](../../iOS/AirSIM/CloudV2/CloudV2View.swift)。网页的统一发现与连接接口尚未接入。配置分发、认证、协议选择由实现层处理；现有管理员配置导入入口不能作为用户接入界面交付。三星六位码流程与模块连接流程仍需由各自适配层承接，不能将示例交互视为已实现的统一配对协议。
