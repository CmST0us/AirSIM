## 页面结构与产品行为

采用左侧阶段引导、右侧单任务正文。主任务有一个明确的主行动，相关设备名称、短标识、状态与检查时间放在同一区域。网页只承担首次准备，不扩展设备管理后台。窄屏改用单列；手机浏览器提供电脑准备说明，不提供无法完成的 USB 初始化表单。

普通入口使用预配置的服务名称。账户授权先于 USB 读取与设备写入；选中 USB 设备不能替代主人认证。主流程以同账户已授权为前提，App 自动出现设备，不要求重复扫码。手机未出现设备时可进入扫码/PIN 分支，识别后仍需在 App 核对设备并确认。

二维码与 PIN 属于同一次短期会话。二维码使用未编码的原生矢量视觉示意，备用配对码为不可用示例；示例与不可激活说明放在画板外评审注释，数字长度不构成协议决定。等待页由真实手机确认事件自动推进，“重新检查”只查询原会话。原型的定时过渡用于演示事件到达，不是生产成功依据。过期后可重新生成，已使用时查询原结果；取消只撤销本次手机确认，保留已有安装和归属。

安装、账户配对、设备独立联网、SIM、短信、电话分别呈现。结果页保留语音待验证和重启恢复未核实的状态，不把“配对完成”当作所有通信能力均已就绪。没有可靠号码时显示“号码未提供”。首次教学要求用户在 App 主动操作，不自动拨号或发短信。

## 异常与恢复

| 状态 | 可执行下一步 | 保留的结果 |
| --- | --- | --- |
| USB 授权取消或拒绝 | 重新选择并允许访问 | 设备未修改 |
| 未发现设备、仅充电线 | 检查供电、换数据线、直接接电脑 | 不进入安装 |
| USB 被占用 | 退出占用程序后重试 | 不抢占其他设备 |
| 型号或软件不支持 | 查看准备说明或换设备 | 不自动刷写固件 |
| 空间不足 | 按设备说明处理后重新检查 | 不开始安装 |
| 误选设备、多设备 | 返回浏览器重新选择并核对 | 不默认选第一台 |
| 拔线、刷新 | 选择原设备并读取原进度 | 不重建身份、不重复接管 |
| 配对码过期 | 更新同次手机确认码；已确认则先查询 | 已完成的安装 |
| 配对码已使用 | 查询本次结果 | 不重复绑定 |
| 结果未知 | 恢复网络后查询本次结果 | 原操作与归属状态 |
| 已配对、无 SIM 或未联网 | 检查供电、SIM 与信号后重查 | 已确认的配对 |
| 已有归属 | 使用原账户或联系原主人 | 原归属，不自动解除 |
| 服务不匹配 | 核对 App 和网页的服务名称 | 原设备配置 |
| 账户授权过期 | 恢复授权后查询原结果 | 原安装进度 |
| 浏览器不支持 | 在受支持的电脑浏览器继续 | 准备说明仍可阅读 |

拔线恢复画板展示“安装已完成、配对结果待确认”的落点。其他中断阶段按原事务实际状态回到对应未完成步骤。原型中的加载页以离散状态过渡演示；真实实现必须等待对应服务或设备结果。

## 视觉与交互规范

- 字体：Noto Sans SC，跨 macOS / Windows 保持中文排版。主色 `#005FCC` 延续 App 视觉；浅深色由语义变量控制。
- 字阶：40/48、32/40、24/32、20/30、16/26、14/22、12/18。正文行高 1.625，短说明保持紧凑。
- 间距：4/8px 基准；按钮高 48px，圆角 8px。状态以文字配合颜色表达。
- 按钮：主次两类，各含 default、hover、focus、active、disabled、loading；加载时阻止重复提交，保留明确文字。设备摘要与状态行复用本地组件。
- 动效：200ms ease-out 淡入；减少动态效果时直接切换。无虚构百分比或预计完成时间。
- 响应式：桌面内容最大宽度 1312px，居中；窄于 900px 折叠阶段导航，正文单列。电脑窗口变窄仍可继续操作，手机承接根据设备能力判断，不能只按宽度判断 USB 支持。
- 无障碍：一个 h1；阶段有序列表和 `aria-current="step"`；状态用 dl；动作按钮与导航链接区分。焦点环清晰，键盘顺序跟随视觉顺序。状态更新使用礼貌播报，阻断错误使用 alert；装饰图 alt 为空，配对码有文本替代。200% 缩放时状态行堆叠、按钮满宽，保留纵向滚动。

## 审稿结论

### Blocking：生产接入前

账户授权和短期配对会话尚无冻结契约，影响账户页、扫码/PIN、过期与已使用状态的真实流转。主控需冻结主人授权方式、同账户设备目录、扫码/PIN 会话和结果查询语义，再接入前端。设计中的“已授权”是目标前置条件。

### Important：设备准备与恢复

浏览器、操作系统、驱动、固件支持组合，以及空间门槛、持久安装、启动与恢复入口待验收。页面应由实际 profile 和事务结果驱动；不能凭电脑联网推断设备在线，也不能将上传软件视为永久安装。

### Polish

当前未发现阻断评审的视觉问题。真实网页实现后还需验证键盘、读屏和 200% 缩放行为。

### Strengths

- 每屏围绕一个任务，设备身份和状态就近呈现。
- 主人授权、USB 权限、手机确认各自明确，同账户省去重复扫码。
- 已配对与当前通信能力分开，离线保留已完成进度。
- 结果未知先查询，取消与普通重试不清空设备。

最先应落实的一项改进：冻结并实现“按本次操作查询结果”的统一接口，使刷新、断网与重复点击都回到同一结果。

## 实施边界

当前实现位于 `service/airsim/web/`，使用系统 WebUSB 选择器、模块本机 Ed25519 证明和 App 八位码确认。正常流程不要求账户、服务器地址、配置文件或协议字段。图稿中的账户目录及扫码/PIN 不作为线上步骤。

裸模块首次安装、稳定开机自启动、OTA 与持久安装恢复仍不在本轮网页实现内；当前网页只连接已经运行 Agent 且已加入服务的目标模块。真实 USB/WebUSB、RM500 物理配对与 ECS 生产验收以单独测试记录为准。

Figma 验证属于设计层检查，不能证明浏览器 USB、账户鉴权、真实扫码、200% 浏览器缩放或辅助技术已经运行通过。原型使用虚构账户、标识与不可用配对码，不包含真实号码、短信或密钥。
